★探校视图 · 我这分能上哪些学校

只按位次，不强制选方向。按院校聚合出一张张校卡：每校标注 985/211/城市/计划数，并把它的专业分成「稳妥能上 / 冲一冲 / 保底」三栏，回答家长第一问。

★探专业 · 我这分能读什么专业，学什么、去哪就业

按你的位次，把够得着的专业方向（专业类）挑出来，逐个给卡片：学什么 / 前景 / 就业率 / 就业方向 / 需要的软实力 / 深造方向 / 就业冷热。可按排序与筛选调整；点卡片上的按钮可直接跳到「智能推荐 / 探校」看对应院校与专业。就业率与冷热为参考，具体以院校公布为准。

★捡漏 · 冲刺档里捡好学校/好专业

只在需要冲刺的档（位次比 1.0–1.3）里找：那些学校层次或专业实力明显高于你位次"该得"的项，或遇上大小年线回落的窗口——用刚够的分，撬动超出预期的院校/专业。
