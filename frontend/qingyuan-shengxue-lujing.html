广东·清远升学路径全景图（2026）

初升高按清远中招、高升大按广东全省。清远 2025 年中考约 6.31 万人、普通高中最低录取控制线 520 分（不含提前批自主招生）；清远市第一中学将 50% 招生计划名额分配到清城、清新两区。本图把“初中→高中→大学”的关键路径一次说清。

① 初升高（清远中招路径）

清远中考总分 800 分（省统一命题），实行考后知分填报，按平行志愿投档，分四个批次录取；被前一批次录取即不再参加后续。2025 年普通高中最低录取控制线 520 分（不含提前批自主招生）。全市约 6.31 万人参加中考，普高招生计划 3.68 万（市直 1.37 万 / 清新 0.53 万 / 英德 0.68 万 / 其他县区合计 1.10 万）。
录取顺序：提前批（公办高中自主招生）→ 第一批（清远一中名额分配）→ 第二批（普通高中统招 + 民办公费 / 普惠 + 中本贯通 / 综合高中班）→ 第三批（中职及技工院校）。 名额分配（清中 50% 到两区）是考生入读优质公办高中的核心渠道；2025 年新实施“两区一体化招生”扩大优质学位供给；中本贯通 / 三二分段则是“规避高考竞争、直通本科 / 高职”的职教路径。

第二批投档

名额分配（清中 50% · 两区）

面向清城、清新两区
名额分配（清中 50% · 两区） 清城 / 清新 · 本校分得名额
清远市第一中学将招生计划的 50% 分配到清城区、清新区（两区），2025 年名额分配计划不设补录。下表为名额分配核心规则；清中 2025 第二批第一次投档清城区 709.88 / 清新区 704.96。清远仅清中面向两区名额分配（非多校 50% 机制），分到各初中的具体名额官方未单列。

民办高中梯队 公费班 / 普惠班 / 自费生

经济承受力需评估
  • 民办公费 / 普惠班在梯度线内由招考办投档。
  • 填报前须看清收费标准与培养模式。
主要校分数线趋势 2024 → 2025
对比清城区主要校 2024 与 2025 第一次投档线：清中 700.85→709.88、广铁公费 717.58→728.29、博爱公费 684.75→700.3；多数校小幅上涨 0~16 分。2025 报名 6.31 万、普高计划 3.68 万。
  • 多数校 2025 较 2024 小幅上涨，部分民办公费线接近持平。
  • 两区一体化招生后优质学位竞争趋于平稳。

第二批（中职及技工院校）

本市中等职业学校及技工院校
本市中职及技工院校（第三批） 升学并重
第三批为中职、技工院校，是“不想走普高、但求一技之长”考生的主要去向，贯通三二分段、中本贯通等升学通道（详见 ③ 中职与四大路径）。
技能导向、升学并重
  • 中职学校贯通三二分段、中本贯通等升学通道。
  • 部分专业对接清远及大湾区产业集群，就业对口率高。
“3+4”中本贯通班 中职 → 本科
清远 2025 年设有“3+4”中本贯通班，前 3 年中职、后 4 年本科，毕业获本科文凭，是“规避高考竞争、直通本科”的职教路径。
  • 最低录取分参照普通高中相应梯度控制线。
  • 被贯通班录取不得参加后续批次；具体计划以清远市招考办公布为准。

② 高升大（广东高招路径）

广东夏季高考实行“3+1+2”，分提前、本科、专科（高职）三个批次，院校专业组平行志愿。录取顺序：强基 → 综评 / 高水平运动队 → 本科提前批 → 普通本科批（含专项）→ 专科提前批（军士 / 卫生专项）→ 普通专科批。
多数路径对天赋 / 特长 / 户籍或定向服务有硬门槛；所有特殊招生都以“参加统一高考”为前提。专项计划、卫生专项、教师专项、公安专项等“带编带岗 / 免学费”路径，是广东考生冲击公办优质本科、锁定稳定就业的关键赛道。清远考生可关注邻近广州、佛山等地高校，以及面向清远等地的教师专项、卫生专项等定向就业路径。

统招主赛道

普通高考统招 无门槛，全体考生
选择面最广的底层路径。广东实行院校专业组平行志愿（分数优先、遵循志愿），普通类分物理、历史两类分开划线、分开投档。
  • 本科批、专科批按“冲 / 稳 / 保”拉开院校专业组梯度。
  • 应届生 3 门选择性考试科目对应的合格性考试须全部合格，否则志愿无效。
清远学子 · 升学在身边 本地高职 + 邻近名校
清远本地高等教育以高职为主，本科阶段可关注邻近广州、佛山等地高校及省内公费定向：
清远职业技术学院市属公办高职，本地就业对口率高
广东碧桂园职业学院民办高职，公益导向、产教融合
广州 / 佛山高校群邻近广州大学城、佛山高校，高铁通达
教师 / 卫生专项面向清远等地定向培养，带编带岗
清远本地本科层次高校较少，考生主要通过普通高考统招报考省内及全国高校；教师专项、卫生专项等定向计划面向清远等地就业。具体专业计划与选科要求以各高校 2026 简章及广东省教育考试院公布为准。

③ 中职与四大路径

清远中考分流后，中职并非“终点”；中本贯通、三二分段可一路贯通至本科 / 高职。广东持续推进职教高考、中高企协同长学制等试点，技能成才通道越来越宽。

  • 紧密对接广东“制造业当家”现代产业体系，报考热度攀升。
职教高考（“3+证书”考试） 中职生升学的统考主通道
广东“3+证书”（语文、数学、英语 + 职业技能证书）是中职生升入本科 / 专科高职院校的主渠道。
  • 可报考省内应用型本科及高职（专科）院校。
  • 技能大赛获奖考生可获免试或加分优待。
技能拔尖人才免试升学 世界技能大赛等
在世界技能大赛获奖、或全国职业院校技能大赛获奖的中职毕业生，可免试入读相应高职院校。
  • 须符合当年广东省免试录取政策与院校招生章程。
  • 是“以赛促学、技能成才”的直通车。
