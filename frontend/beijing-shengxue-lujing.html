① 初升高（中招路径）

2026 北京中招总分 510 分，考后知分填报，分三阶段录取；被前一阶段录取即不再参加后续。
录取顺序：提前招生 → 指标分配招生（校额到校 / 市级统筹）→ 统一招生 → 志愿征集。 另有「登记入学」「1+3 培养实验」属于考前的提前锁定通道，不走常规志愿。
1

提前招生

被录取即锁定，不再参加后续批次
普通高中提前招生 看专项 / 校内推荐
含集团直升、艺术 / 体育 / 科技特长生、小语种特色班、美术班等招生类型。
  • 集团直升拟录取考生在提前批录取，不再填志愿。
  • 特长生须参加学校专业测试，合格方可填报。
  • 美术班等通常也需专业测试。
中职 / 综合高中自主招生 4 月底–5 月初
2026 年全市 83 所中职校计划自主招生约 1.8 万余人，含五年制高职、中专、技校、职高四类。
适合有专业兴趣 / 动手强的学生
  • 考核含笔试 + 面试 + 专业测试。
  • 一旦录取不再参加统一招生，须谨慎。
登记入学（普高“提前车”） 仅东城 / 西城 / 平谷
部分普通高中试点（2026 年共 5 所），无需中考分数竞争。
连续 3 年学籍 + 普高资格 综评 B 等 + 地理/生物 B 等
  • 每生限报 1 所试点校，多报取消资格。
  • 录取后学考只记“合格 / 不合格”，不填志愿。
“1+3”培养实验 · 市级 + 区级 初二阶段报名
全市 14379 人（市级 830 / 区级 13549，175 校）。市级 6 校、区级按区按校可查，录取后免中考竞争。
普高资格 + 同校连续 2 年学籍
  • 市级计划（城六区）+ 区级计划（本区），各选 1 所。
  • 弹窗内分“市级 / 区级”两部分，区级可选区 + 搜校名。

指标分配招生

提前招生之后、统一招生之前
校额到校 总分 ≥ 430 且综评 B 等
优质高中 不低于 50% 计划分配到初中校。海淀 2026 共 2499 人（六小强 1127 + 其他 1372）。可查本校名额 / 人大附中分配。
连续 3 年学籍 8 个志愿 / 每校 2 专业
  • 弹窗分三部分：①海淀调整明细 ②按初中查（86 所）③按高中查（人大附中）。
  • 与市级统筹可混合填报；录取后不参加统招。
市级统筹 看区排名 + 分配名额
跨区统筹优质教育资源，面向全市分配，弱区考生可借此进入优质高中。
与校额到校同批次
  • 关注招生校在本区的分配名额与区排名。
  • 可与校额到校志愿混报。
3

统一招生

12 个志愿，每志愿 2 专业
普通高中普通班 按成绩 / 排名 / 计划
多数考生的主流选择，按“冲 / 稳 / 保”梯度拉开志愿。
  • 普通高中招生规模约 9.5 万人（2026）。
  • 跨区招生受严格控制，民办高中主要面向本区。
中外合作办学项目（国际班） 面向办学所在区
统一招生批次录取，课程融合国内核心课 + AP / A-Level / IB 等国际课程。
有留学规划、英语好、家庭预算足
  • 成绩公布后、填志愿前须参加外语能力测试。
  • 学费较高（跨境交流费用），需结合承受力。
贯通培养项目 总分 ≥ 380
高端技术技能人才贯通培养（中本贯通 / 高本贯通），7 年（3 中 + 2 高 + 2 本），2026 年起调整至统一招生批次。
想稳拿本科、规避高考竞争
  • 升本通过率较高；本科证标注“专升本”，第一学历为专科。
  • 部分专业须加试，合格方可填报。
五年制高职 / 中专 / 技校 / 职高 全市招生
中职类学校多数在全市范围招生，不对各区分配计划。
  • 注意部分专业有体检限制（色盲、色弱等）。
  • 统一招生未录满可参加志愿征集。

② 高升大（高招路径）

北京高考录取分本科提前批 A 段（2 志愿）、提前批 B 段（20 个院校+专业）、普通批（30 个院校专业组）、专科批（20 志愿）。路径虽多，多数对天赋 / 特长 / 户籍有硬门槛。

统招主赛道

普通高考统招 无门槛，全体考生
选择面最广的底层路径，除保送、体育单招外，所有特殊招生都以参加统一高考为前提。
  • 本科提前批（强基 / 综评 / 双培外培 / 军警 / 师范 / 艺术 / 招飞 / 港澳统招）+ 普通批平行志愿。
  • 纯比分数，中低分段公办本科竞争激烈。

③ 中职细分与四大路径

从中考分流后，中职并非“终点”；贯通培养可一路拿本科。专家把北京中考升学概括为四条主路径。
职

中职升学与就业双轨

五年一贯制高职 拿大专
入校后接受五年一贯制高等职业教育，毕业获大专学历。
“3+2”中高职衔接 转段升高职
中职阶段后通过转段测试进入对应高职院校，继续深造。
贯通培养项目 拿本科（专升本）
中本 / 高本贯通，7 年（3 中 + 2 高 + 2 本），升本通过率高；第一学历为专科。
普通中职 / 职高 / 技校 就业或继续升学
多数在全市招生；可经高职自主招生 / 单招升入高职。
4

北京中考升学四大路径（专家概括）

路径 1 · 升入高中主流路径，普高升学率约 75%（部分区接近 100%），目标三年后升入理想大学。
路径 2 · 中等职业教育约 20% 考生选择；热度回升，贯通培养 7 年可拿本科证（专升本）。
路径 3 · 出国留学占比不到 5%；公办国际部 / 民办国际学校，受国际形势与就业影响趋理性。
路径 4 · 往届生报考无“复读”概念，可往届生身份再考；总分减 5 分，且不能报名额分配批次。
给家长的提醒：中考没有“复读”说法，符合条件的可“往届生”身份再考，但次年总分减 5 分，且只能报提前批与统招批，名额分配（校额到校 / 市级统筹）不能报。规划宜早，避免临时被动。
数据口径与免责：本页依据北京市教委《关于做好 2026 年高级中等学校考试招生工作的意见》、北京教育考试院 2026 年中招 / 高招政策、央广网、北青网等公开报道整理，政策口径为 2026 年。具体招生计划、录取分数线、志愿填报时间与批次规则，请以北京教育考试院（www.bjeea.cn）及当年官方发布为准。本页仅供参考，不构成报考建议。
