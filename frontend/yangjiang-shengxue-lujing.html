① 初升高（阳江中招路径）

阳江中考总分 1,000 分（2025 届仍按旧方案；2025 秋季七年级起改革为 800 分），按志愿、计分科目成绩择优录取，实行自主招生、名额分配（指标生）、统一招生三类录取。2025 年九年级约 4.02 万人参加中考；普通高中最低录取控制线官方未公布统一数（以各校普通生线为准，2024 年民办最低控制线 623 分）。阳春市 2025 年普高招生计划 8,450 人（含民办阳春博泰实验）。
录取类型：自主招生（体艺 / 学科特长）→ 名额分配（指标生 ≥50%）→ 统一招生（普通生）。 名额分配（指标生）是薄弱 / 农村初中学生降分入读优质公办高中的核心渠道；中本贯通（3+4）则是“规避高考竞争、直通本科”的职教跃升路径。

② 高升大（广东高招路径）

广东夏季高考实行“3+1+2”，分提前、本科、专科（高职）三个批次，院校专业组平行志愿。录取顺序：强基 → 综评 / 高水平运动队 → 本科提前批 → 普通本科批（含专项）→ 专科提前批（军士 / 卫生专项）→ 普通专科批。
多数路径对天赋 / 特长 / 户籍或定向服务有硬门槛；所有特殊招生都以“参加统一高考”为前提。专项计划、卫生专项、教师专项、公安专项等“带编带岗 / 免学费”路径，是广东考生冲击公办优质本科、锁定稳定就业的关键赛道。阳江考生还可重点关注家门口的本土高校（广东海洋大学阳江校区、阳江职业技术学院等）。

统招主赛道

普通高考统招 无门槛，全体考生
选择面最广的底层路径。广东实行院校专业组平行志愿（分数优先、遵循志愿），普通类分物理、历史两类分开划线、分开投档。
  • 本科批、专科批按“冲 / 稳 / 保”拉开院校专业组梯度。
  • 应届生 3 门选择性考试科目对应的合格性考试须全部合格，否则志愿无效。
阳江本土高校 · 升学在身边 家门口的名校
阳江高等教育持续布局，考生无需远行即可冲击高水平大学：
广东海洋大学阳江校区公办本科，理工农海多学科，本地就业对口率高
阳江职业技术学院公办高职专科，应用型人才培养
广东海洋大学阳江校区为校地共建高水平本科校区，以普通高考统招为主；阳江职业技术学院以专科统招与三二分段衔接为主。具体专业计划与选科要求以各高校 2026 简章及广东省教育考试院公布为准。

③ 中职与四大路径

阳江中考分流后，中职并非“终点”；中本贯通、三二分段可一路贯通至本科 / 高职。广东持续推进职教高考、中高企协同长学制等试点，技能成才通道越来越宽。

广东“3+证书”（语文、数学、英语 + 职业技能证书）是中职生升入本科 / 专科高职院校的主渠道。
  • 可报考省内应用型本科及高职（专科）院校。
  • 技能大赛获奖考生可获免试或加分优待。
技能拔尖人才免试升学 世界技能大赛等
在世界技能大赛获奖、或全国职业院校技能大赛获奖的中职毕业生，可免试入读相应高职院校。
  • 须符合当年广东省免试录取政策与院校招生章程。
  • 是“以赛促学、技能成才”的直通车。
