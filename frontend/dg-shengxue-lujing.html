① 初升高（东莞中招路径）

东莞中考总分 800 分，实行考后知分填报，按“分数优先、遵循志愿”投档，分三个批次录取；被前一批次录取即不再参加后续。2025 年普通高中最低录取控制线 520 分（不含提前批自主招生）。
录取顺序：提前批（自主招生）→ 第一批（普通高中统招）→ 第二批（中职及技工院校）。 名额分配（十一大校 50%）是户籍生降分入读优质公办高中的核心渠道；综合高中试点为 2025 年新设，构建“学术 + 技能”双轨；中本贯通 / 三二分段则是“规避高考竞争、直通本科 / 高职”的职教路径。

第二批（中职及技工院校）

本市中等职业学校及技工院校
本市中职及技工院校（第二批） 升学并重
第二批为中职、技工院校，是“不想走普高、但求一技之长”考生的主要去向，贯通三二分段、中本贯通等升学通道（详见 ③ 中职与四大路径）。
技能导向、升学并重
  • 中职学校贯通三二分段、中本贯通等升学通道。
  • 部分专业对接东莞“制造业当家”产业集群，就业对口率高。
“3+4”中本贯通班 中职 → 本科
东莞 2025 年设有“3+4”中本贯通班，前 3 年中职、后 4 年本科，毕业获本科文凭，是“规避高考竞争、直通本科”的职教路径。
  • 最低录取分参照普通高中相应梯度控制线。
  • 被贯通班录取不得参加后续批次；具体计划以东莞市教育局公布为准。

② 高升大（广东高招路径）

广东夏季高考实行“3+1+2”，分提前、本科、专科（高职）三个批次，院校专业组平行志愿。录取顺序：强基 → 综评 / 高水平运动队 → 本科提前批 → 普通本科批（含专项）→ 专科提前批（军士 / 卫生专项）→ 普通专科批。
多数路径对天赋 / 特长 / 户籍或定向服务有硬门槛；所有特殊招生都以“参加统一高考”为前提。专项计划、卫生专项、教师专项、公安专项等“带编带岗 / 免学费”路径，是广东考生冲击公办优质本科、锁定稳定就业的关键赛道。东莞考生还可重点关注家门口的本土高校（东莞理工、大湾区大学等）。

统招主赛道

普通高考统招 无门槛，全体考生
选择面最广的底层路径。广东实行院校专业组平行志愿（分数优先、遵循志愿），普通类分物理、历史两类分开划线、分开投档。
  • 本科批、专科批按“冲 / 稳 / 保”拉开院校专业组梯度。
  • 应届生 3 门选择性考试科目对应的合格性考试须全部合格，否则志愿无效。
东莞本土高校 · 升学在身边 家门口的名校
东莞高等教育快速崛起，考生无需远行即可冲击高水平大学：
东莞理工学院应用型本科强校，本地就业对口率高
大湾区大学2024 年首招，高起点、理工科导向
广东科技学院民办本科，应用型人才培养
东莞城市学院民办本科，多科性应用型高校
大湾区大学为新建高水平研究型大学，2024 年起在粤招生；东莞理工以普通高考统招为主。具体专业计划与选科要求以各高校 2026 简章及广东省教育考试院公布为准。

③ 中职与四大路径

东莞中考分流后，中职并非“终点”；中本贯通、三二分段可一路贯通至本科 / 高职。广东持续推进职教高考、中高企协同长学制等试点，技能成才通道越来越宽。

中职升学具体通道
