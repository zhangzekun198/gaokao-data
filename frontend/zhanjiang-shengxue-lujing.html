① 初升高（湛江中招路径）

湛江中考总分 760 分（“4+3” 模式），设第一批、第二批两个批次录取，实行“分数优先、遵循志愿”平行志愿投档；第一批设 3 个志愿组（特长生 / 指标生 / 统招 + 中本贯通），第二批设 3 个志愿组（特长生 / 统招 / 中职）。2025 年普通高中招生计划 6.12 万（统招 36,759 + 指标生 15,582 + 自主 8,859），第一批最低录取控制线 450 分、第二批 350 分，全市约 11.1 万名初三考生报考。
录取顺序：第一批（志愿组1 特长生 → 志愿组2 指标生 → 志愿组3 统招 + 中本贯通）→ 第二批（志愿组1 特长生 → 志愿组2 统招 → 志愿组3 中职）。 指标生（50% 到校）是考生降分入读优质公办高中的核心渠道；自主招生（特色实验班 / 体艺特长生 / 民办自主）为特长与拔尖学生提供多元路径；中本贯通则是“规避高考竞争、直通本科”的职教路径。

② 高升大（广东高招路径）

广东夏季高考实行“3+1+2”，分提前、本科、专科（高职）三个批次，院校专业组平行志愿。录取顺序：强基 → 综评 / 高水平运动队 → 本科提前批 → 普通本科批（含专项）→ 专科提前批（军士 / 卫生专项）→ 普通专科批。湛江考生可重点关注省内及本土高校（广东海洋大学、岭南师范学院、广东医科大学、湛江科技学院等）。
多数路径对天赋 / 特长 / 户籍或定向服务有硬门槛；所有特殊招生都以“参加统一高考”为前提。专项计划、卫生专项、教师专项、公安专项等“带编带岗 / 免学费”路径，是广东考生冲击公办优质本科、锁定稳定就业的关键赛道。湛江考生可重点关注家门口的本土高校（广东海洋大学、岭南师范学院、广东医科大学等）。

③ 中职与四大路径

湛江中考分流后，中职并非“终点”；中本贯通、三二分段可一路贯通至本科 / 高职。广东持续推进职教高考、中高企协同长学制等试点，技能成才通道越来越宽。

中职升学具体通道

中本贯通（中职 → 本科） 7 年拿本科证
前 3 年中职、后 4 年本科，毕业获本科文凭。2026 试点扩至 9 校 11 专业 318 人（2025 仅 2 校 40 人），最低线普高第三梯度线（广州 632）。
  • 中本贯通采用普通高中梯度控制线上志愿优先投档。
  • 被录取后不得参加后续批次；补录先于普通高中进行。
中高职三二分段 中职 3 年 + 高职 2 年
2026 年广东三二分段 399 专业、计划 18,996 人，录取 15,620 人，其中 5,769 人达公办普高线。
  • 中职阶段后通过转段考核升入对口高职。
  • 紧密对接广东“制造业当家”现代产业体系，报考热度攀升。
职教高考（“3+证书”考试） 中职生升学的统考主通道
广东“3+证书”（语文、数学、英语 + 职业技能证书）是中职生升入本科 / 专科高职院校的主渠道。
  • 可报考省内应用型本科及高职（专科）院校。
  • 技能大赛获奖考生可获免试或加分优待。
技能拔尖人才免试升学 世界技能大赛等
在世界技能大赛获奖、或全国职业院校技能大赛获奖的中职毕业生，可免试入读相应高职院校。
  • 须符合当年广东省免试录取政策与院校招生章程。
  • 是“以赛促学、技能成才”的直通车。
