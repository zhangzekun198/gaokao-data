① 初升高（韶关中招路径）

韶关中考总分 720 分，2025 年全市约 8.83 万人参考，27 所普通高中计划招生 2.33 万人（公办 23 / 民办 4）；2025 年起不设置提前批，分第一、二、三、四批次录取，被前一批次录取即不再参加后续。公办优质高中指标到校比例不低于 50%，统分指标生在普通生线下 50 分内投档。
录取顺序：第一批次（市属优质高中 + 民办公办生等）→ 第二批次（“3+4”中本贯通 + 普通高中）→ 第三批次 → 第四批次。 指标到校（北江中学、市一中、田家炳中学面向市辖三区）是户籍生降分入读优质公办高中的核心渠道；自主招生（含体艺特长生）融入各批次录取；“3+4”中本贯通 / 三二分段则是“规避高考竞争、直通本科 / 高职”的职教路径。

自主招生（含体艺特长生）

融入各批次 · 中考 + 校测择优
自主招生（含体艺） 学科科技 / 体育艺术
韶关 2025 年不设提前批，自主招生（含体育艺术特长生）融入各批次录取：先参加学校专项考核并取得资格，再按“初中学业水平考试成绩 + 学校专项考核”合成总分择优录取。全市普通高中自主招生总计划 2,065 人。
各批次录取学科 / 体艺专长
  • 学科科技类与体育艺术类，具体项目由各校自主招生方案确定。
  • 须先参加学校专项考核并取得资格，方可填报相应志愿。
体育 / 艺术特长生 融入各批次 · 估算
韶关普通高中体艺特长生纳入自主招生，在各批次录取，按“中考成绩 + 学校专项考核”择优。全市普通高中自主招生总计划 2,065 人（含体艺）。
  • 具体项目与计划以各校自主招生简章为准。
  • 官方未发布全市体艺汇总表，本页为政策口径估算。
统一录取与同分规则 分数优先 · 志愿优先
普通生按志愿、中考成绩、综合素质评价及招生计划从高分到低分投档；同分时按“语文→数学→英语”顺序比较，再参考综合素质评价。
全市统一规则
  • 自主招生（含体艺）按学校方案投档录取。
  • 凡被前一批次录取的考生，不再参加后续批次投档。

② 高升大（广东高招路径）

广东夏季高考实行“3+1+2”，分提前、本科、专科（高职）三个批次，院校专业组平行志愿。录取顺序：强基 → 综评 / 高水平运动队 → 本科提前批 → 普通本科批（含专项）→ 专科提前批（军士 / 卫生专项）→ 普通专科批。
多数路径对天赋 / 特长 / 户籍或定向服务有硬门槛；所有特殊招生都以“参加统一高考”为前提。专项计划、卫生专项、教师专项、公安专项等“带编带岗 / 免学费”路径，是广东考生冲击公办优质本科、锁定稳定就业的关键赛道。韶关考生还可重点关注家门口的本土高校（韶关学院等）。
